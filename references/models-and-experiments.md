# 模型分流与实验

平台不是商业模式。先问钱由谁、为什么、何时支付；同一项目可能叠加几种模型，只读与当前问题相关部分。下列项目是覆盖类型，不是赚钱推荐。

| 模型 | 特别核查 | 可选最小验证与局限 |
|---|---|---|
| 自媒体、直播、广告收入 | 先明确表达、职业、业务获客还是直接收入目的；细分赛道、真实付费方、普通账号变现证据、平台资格、收入稳定性与总工时 | 分别核查内容生产与商业路径；小批内容检验产能和目标受众，具体付费需求、线索、成交或结算检验商业性；涨粉与播放不能替代收入证据，不编造赛道成功率 |
| 达人带货、联盟分佣、短视频电商 | 佣金结算、退款追回、样品和流量支出，是否依赖爆款 | 用合规样品完成少量真实内容，追踪实际结算佣金与总工时，不只看下单GMV |
| 国内电商、选品转售、一件代发 | 同款竞争、供货质量、缺货、发货责任、平台费用 | 小批现货或核实过的一件代发卖给独立客户，记录退货和净贡献；代发不免除卖家责任 |
| 跨境平台卖货 | 目的国、进口及产品要求、体积重量、清关、仓储、回款、退货 | 先取得门到门报价和合规核查，再少量真实发货；国内测试不证明海外经济模型 |
| 独立站、DTC | 客流来源、素材、信任、支付和弃购、履约 | 明码标价页面可先测触达及意向；实际购买与履约另测。无支付页不能给出成交率 |
| 小众消费品品牌、OEM、手作 | 审美溢价、打样、MOQ分摊、包装、质检、复购证据 | 用安全合规的现成样品、小批手作或低MOQ版本测试具体购买理由；大货变化后须重新验证关键差异 |
| 技能接单、咨询、设计、摄影、代运营 | 谁付钱、获客、作品、修改次数、交付边界和回款 | 卖一个小范围付费交付，算完整工时和返工；低资金不代表低技能或容易获客 |
| 数字产品、模板、课程、社群 | 真实专业能力、版权、售后、平台抽成、信任和持续维护 | 做一项可交付小产品给明确客群；免费资料下载不等于付费意愿；不捏造收益承诺 |
| AI工具、自动化服务、微型SaaS | 业务痛点、替代方案、API成本、数据权限、稳定性与留存 | 经授权以人工辅助交付一个付费工作流，再决定开发；AI降低生产成本不证明存在客户 |
| 本地服务、摆摊、寄售、团购 | 场地许可、抽成、天气季节、损耗、劳动时间、结算 | 合规短期试卖或少量寄售；线下闻香可测现场购买，不能直接推出线上广告转化 |
| 加盟、代理、无人零售、设备租赁 | 真实门店净现金、合同退出、租金、设备残值、供货绑定、收益是否依赖招募 | 先核实独立经营者流水与全部支出，未核实前不交加盟费和定金；参观样板店不足 |
| 二手转卖、信息撮合、资源中介 | 货源稳定、鉴定、纠纷、授权、撮合收费条件 | 少量合法真实交易，记录周转和损失；偶然捡漏不代表可复制供应 |

## 情景算账示例（全部是假设，不是市场报价）

某商品每单净收入100元，货品30元，包装物流12元，平台支付3元，预期售后损失5元，获客前贡献50元。若每名新客只买一单，获客成本35元，则每单获客后贡献15元。试验固定支出3000元，需要约200单才覆盖该项固定支出，尚未计经营者时间。获客成本升到55元，则每单贡献为负，不能靠增加销量自动解决。

另外，采购1000件需先付30000元，库存即使尚未出售也已占用现金。不要把每单贡献为正误读成现金足够。若一名新客买多单，需按真实订单分布算客户贡献，不能混用以上简化假设。

## 试验卡

- 我们最需要验证的是：……
- 证伪方式：什么实际结果会说明这个假设不成立？
- 对象／产品与价格／渠道：……
- 预算上限／工时上限／截止时间：……（先确认承担得起）
- 记录：触达、有效访问、明确意向、独立付费、履约退款、实际成本；只选相关指标。
- 通过条件：根据经济模型设定，说明样本仍有哪些不确定性。
- 停止条件：预算、时间、合规、交付任一触线；不可因不甘心自动续费。
- 结果不确定：是触达错人、产品变化还是样本不足？下一次实验仍须重新确认上限。

没有付费也可能是流量不匹配，不应立刻宣布整个市场无需求；但不能以此无限延期验证。先判断实验设计是否真的检验了核心假设。

## 完整运营计时实验

适用于用户只会估计“每天一小时”，却没做过目标质量的内容或店铺运营。先通过资金承受核查，再选择无需新增重大支出的样本。

1. 选一个具体产品、一类目标客户、一个渠道和一项待测购买理由。预先说明什么质量足以测试，例如实物准确、信息清楚、风格基本一致，不以“终于完美”为结束条件。
2. 用户自行完成一次完整制作，分项记录调研、构思写稿、布景拍摄或AI制图、筛选修正、排版上架、返工的实际工时；另记起步学习、工具搭建、外包费用、协作审核与等待。若仅做草稿，标明发布及真实运营仍未验证。
3. 在约定观察期记录实际互动、咨询、数据复盘和相关订单履约工时。无人咨询不代表有销量后客服也为零；按订单情景估算待发生工作，并注明未知。
4. 将实测工时换算为预期周频率，再加固定运营任务与合理波动余量；与可持续专注时间及可响应时段比较。未测得的成本不能默认零，也不能随意填行业标准。
5. 用两条线评价：是否按上限完成可用交付；是否取得相关客户证据。作品精美不证明需求，赶快发布也不证明具备运营能力。若超时，先检验质量目标和范围能否缩减，不能默认无限增加时间。

朋友式示例：

“每天一小时，折成一周大约七小时，但我们还不知道七小时够完成什么。先拿你想卖的一件产品做一篇：从选题、配图到你觉得可以发布，全程记一下时间。假设这一篇实测用了四小时，每周两篇就已超过七小时，还没有算咨询和复盘。这是假设示例，不是行业工时。我们要用你的实测决定：少发一点、简化制作、付费外包，还是暂缓。”

“你希望画面很有氛围感，这个目标可以保留。我们先做一张看能否落地；如果要摄影师，先把拍摄、布景、修图、修改次数和使用权问清楚。漂亮图片可能有帮助，但我们也要检查：客户需要的购买信息是否清楚，额外制作投入是否值得，而不是一直修到自己满意还没有卖过一次。”
