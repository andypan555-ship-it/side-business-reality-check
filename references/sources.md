# 方法来源

检索日期：2026-10-16。下面是方法参考，不是中国或其他地区的法律依据，也不是对任何特定副业的成功背书。

- SBA：商业规划、市场调查、竞争、启动成本与盈亏平衡。https://www.sba.gov/counseling/plan-your-business/
- SBA：启动资金需要覆盖不同支出和现金需要。https://www.sba.gov/blog/2017/2017-01/how-estimate-starting-costs/
- Shopify：电商获客、贡献与回收期。属于商业平台发布的方法资料，平台营销表述不作为中立实证。https://www.shopify.com/blog/ecommerce-customer-acquisition
- YC：通过客户了解需求。偏创业公司场景，不能照搬其融资和增长目标到普通副业。https://www.ycombinator.com/library/IP-dalton-michael-secrets-you-can-learn-from-your-customers

应用：个人风险前置、分阶段追问、四类建议、最小实验卡是本技能根据用户目标设计的流程，不冒充上述来源的标准体系。

实时查证：平台费率、支付费用、政策、产品准入、进口要求、税费、广告限制和授权等会变化，先问清经营地、销售目的地、产品与平台，再查官方文档并标注日期。搜索不到不代表不存在。跨境香氛可检查配方与分类、标签、安全、运输及责任等适用要求，但不得不查目的地就断言某证书必需或不必需。

不使用未经核实的行业失败率、统一CAC、转化率或复购率替用户做决定。保留来源链接、适用条件和不确定性；无法联网时给待查清单与获取路径。
